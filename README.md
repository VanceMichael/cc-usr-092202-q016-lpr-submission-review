# LPR报价报送审查

全国银行间同业拆借中心 LPR 报价报送审查后台：审查报价机构的分期限（一年期、五年期以上）报送，冻结可复核且相互隔离的正式计算输入。

## 解决的问题

报价通过加密邮件与报送表混合提交，截止前更正、截止后补报、重复报送、单位口径错误混杂，审核人员难以判断异常值是市场变化、口径错误还是重复提交。本系统提供：

- **分期限独立保存**：一年期（1Y）与五年期以上（5Y_PLUS）报价、数据来源（EMAIL/SPREADSHEET）、数据依据说明、修订理由、审查意见分别留档。
- **报送窗口与版本化**：截止前更正形成新版本且历史版本全部保留；截止后的补报/更正只登记为逾期，绝不进入当期有效报价。
- **格式与单位校验**：按报价样例规则校验非数值、越界、错误步长；识别误按小数比例（`0.0305`）与误按基点（`305`）报送。
- **冻结阻断**：缺报、重复报送、单位/格式错误、无资格机构报送未处置完毕前阻断冻结；每个期限做纳入家数（法定数量）检查。
- **异常提示而非自动剔除**：较上一期公布值、当期有效报价中位数偏离超阈值时提示，由人工结合机构报送依据判断是市场变化还是口径错误。
- **回避分派 + 双人确认**：与机构有关联的审查人员依法回避；任何剔除或恢复均须两名不同审查人员一致确认，并保存**决定当时的规则版本**。
- **机构隔离视图**：机构账号只能查看自身全部版本与对本机构的结论，看不到任何其他机构数据；审查人员对其回避机构的报价数值脱敏。
- **冻结包可复核**：完整列出每期限纳入范围（来源事件、版本、依据）、排除理由、逾期留痕、全部双人决定与冻结签署记录，并内嵌规则快照，不提前泄露其他机构数据。

## 关键规则（以 `period-2026-09.json` 为准）

- 报送窗口 `2026-09-18 09:00` 至截止 `2026-09-21 08:30`（+08:00）；截止时刻之后一律 `late`。
- 报价单位为百分数（%），步长 0.01，区间 [0.5, 10]：
  - `0 < 值 < 0.5` → 疑似误按小数比例；`值 ≥ 20` → 疑似误按基点。
- 异常：较上一期偏离 > 8bp，或较当期有效报价中位数偏离 > 5bp（有效报价 ≥3 家时比较中位数）。
- 法定数量：每个期限纳入计算的有效报价不少于 5 家。
- 双人决定动作：`EXCLUDE` 剔除 / `RESTORE` 恢复 / `CONFIRM_INCLUDE` 异常确认纳入 / `CONFIRM_EXCLUDED` 确认不纳入 / `IGNORE_DUPLICATE` 重复以原件为准 / `PROCEED_WITHOUT` 缺报属实不参与。

## 可复核性保证

每条冻结包内的双人决定都固化 `rules_version`（如 `R2026-09-01`）、两名审查人员、意见与时间；冻结包同时内嵌完整 `rules_snapshot`，即使日后规则调整，历史正式报价的形成过程仍可按当时规则复核。
